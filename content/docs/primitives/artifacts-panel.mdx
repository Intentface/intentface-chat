Artifacts Panel is the right-hand surface that opens beside the thread to show a
generated artifact in full. It's open-gated — mounted only while `open` — and
slides in over a fixed width. The header carries the title and a close button;
the footer copies the raw content.

<ComponentPreview name="artifacts-panel-basic" />

## Installation

```bash
bunx shadcn@latest add @intentface/artifacts-panel
```

## Anatomy

```tsx
<ArtifactsPanel open={open}>
  <ArtifactsPanel.Header title={title} onClose={close} />
  <ArtifactsPanel.Viewport>
    <ArtifactsPanel.Content>{content}</ArtifactsPanel.Content>
  </ArtifactsPanel.Viewport>
  <ArtifactsPanel.Footer content={content} />
</ArtifactsPanel>
```

Panel width comes from the `--artifacts-panel-width` CSS variable, so a chat
layout can animate the thread's width against it.
