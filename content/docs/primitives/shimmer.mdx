---
title: Shimmer
description: A text loading affordance — a highlight sweeps across the characters while content is pending.
---

Shimmer animates a gradient highlight across text to signal pending work. The
package owns the spread math (highlight width scales with the string length) and
exposes it as CSS variables; the styled wrapper paints the gradient and runs the
keyframes, so the motion lives entirely in CSS.

<ComponentPreview name="shimmer-basic" />

## Installation

```bash
bunx shadcn@latest add @intentface/shimmer
```

## Anatomy

```tsx
<Shimmer>Generating response…</Shimmer>
```

Rendered as a different element, with a custom cadence:

```tsx
<Shimmer as="span" duration={1.5} spread={3}>
  {label}
</Shimmer>
```

## Props

export const rootProps = [
  { name: "children", type: "string", description: "The text to shimmer (string only — the spread is derived from its length)." },
  { name: "as", type: "ElementType", default: '"p"', description: "The rendered element." },
  { name: "duration", type: "number", default: "2", description: "Sweep duration in seconds (exposed as --shimmer-duration)." },
  { name: "spread", type: "number", default: "2", description: "Highlight width per character in px (exposed as --shimmer-spread)." },
