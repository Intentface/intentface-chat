---
title: Steps
description: A collapsible timeline of a run — reasoning, tool calls, and answered questions as chronological steps.
---

Steps renders an agent run as a vertical timeline. Each step is a row with a
status; steps with children expand to reveal detail. `Steps.ToolCall` and
`Steps.AskUser` derive a label, status, and summary from a tool part via the
package's helpers, so you pass the part and they render the row.

## Anatomy

```tsx
<Steps>
  <Steps.Header>Steps</Steps.Header>
  <Steps.Content>
    <Steps.Step label="Read the request" status="complete" />
  </Steps.Content>
</Steps>
```

Driven from message segments — tool parts render themselves:

```tsx
<Steps defaultOpen={isStreaming}>
  <Steps.Header>{header}</Steps.Header>
  <Steps.Content>
    {segments.map((seg) =>
      seg.type === "reasoning" ? (
        <Steps.Step label={seg.header} status="complete">
          <Steps.Body>{seg.body}</Steps.Body>
        </Steps.Step>
      ) : seg.part.type === "tool-askUser" ? (
        <Steps.AskUser part={seg.part} />
      ) : (
        <Steps.ToolCall part={seg.part} />
      ),
    )}
  </Steps.Content>
</Steps>
```
