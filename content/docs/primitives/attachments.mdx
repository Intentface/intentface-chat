---

Attachments renders the pending-file tray that sits above the composer input. It
ships the attachment model (accept matching, blob-URL lifecycle, send
preparation) in the package; the styled tray animates items in and out and can
project a global drop zone anywhere in the app.

## Anatomy

```tsx
<Attachments show={items.length > 0}>
  {items.map((item) => (
    <Attachments.Item key={item.id} item={item}>
      <Attachments.Remove onRemove={() => remove(item.id)} />
    </Attachments.Item>
  ))}
</Attachments>
```

With a drop zone and a picker trigger:

```tsx
<>
  <Attachments.Dropzone visible={isDragging} variant="global" />
  <Attachments show={items.length > 0}>
    {items.map((item) => (
      <Attachments.Item key={item.id} item={item}>
        <Attachments.Remove onRemove={() => remove(item.id)} />
      </Attachments.Item>
    ))}
  </Attachments>
  <Attachments.Trigger onClick={openFileDialog} />
</>
```

## Utilities

The wrapper re-exports the package's attachment helpers so you import them from
one place: `toAttachmentItem`, `matchesAccept`, `prepareAttachmentsForSend`,
`revokeAttachmentUrl`, and the `DEFAULT_ATTACHMENT_*` limits.
