Step Queue is the compact, live counterpart to [Steps](/docs/primitives/steps).
While a run is in flight the composer surfaces it: collapsed, it masks down to
the latest item; expanded, it shows up to five with a fade at the edges.
Clicking toggles it. The active label shimmers.

## Anatomy

```tsx
<StepQueue>
  <StepQueue.Item>
    <StepQueue.Icon>{icon}</StepQueue.Icon>
    <StepQueue.Label active={isActive}>{label}</StepQueue.Label>
  </StepQueue.Item>
</StepQueue>
```

Driven from derived panel state inside the composer's panel:

```tsx
<StepQueue open={isOpen} onOpenChange={setOpen}>
  {steps.map((step) => (
    <StepQueue.Item key={step.key}>
      <StepQueue.Icon>{step.kind === "thinking" ? <BrainIcon /> : <DotIcon />}</StepQueue.Icon>
      <StepQueue.Label active={step.key === activeKey}>{step.label}</StepQueue.Label>
    </StepQueue.Item>
  ))}
</StepQueue>
```
