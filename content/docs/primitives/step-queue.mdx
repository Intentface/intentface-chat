## Usage guidelines

- **Live step stack** — the compact, in-flight counterpart to [Steps](/docs/primitives/steps), surfaced by the composer while a run streams.
- **Collapse / expand** — collapsed it masks down to the latest item; expanded it shows up to five with a fade at the edges. Click or Enter/Space toggles it.
- **Active shimmer** — the item marked `active` shimmers.
- **State via `useStepQueue`** — read and toggle the open state from anywhere inside.
- **Get started** — see [Installation](/docs/installation) to add the package and copy the component.

## Anatomy

```tsx
<StepQueue>
  <StepQueue.Item>
    <StepQueue.Icon>{icon}</StepQueue.Icon>
    <StepQueue.Label active={isActive}>{label}</StepQueue.Label>
  </StepQueue.Item>
</StepQueue>
```

Driven from derived panel state inside the composer's panel:

```tsx
<StepQueue open={isOpen} onOpenChange={setOpen}>
  {steps.map((step) => (
    <StepQueue.Item key={step.key}>
      <StepQueue.Icon>{step.kind === "thinking" ? <BrainIcon /> : <DotIcon />}</StepQueue.Icon>
      <StepQueue.Label active={step.key === activeKey}>{step.label}</StepQueue.Label>
    </StepQueue.Item>
  ))}
</StepQueue>
```

## Accessibility

The root is a toggle: `role="button"`, `tabIndex={0}`, and Enter/Space expand or
collapse the queue, so it's operable by keyboard.

## API reference
