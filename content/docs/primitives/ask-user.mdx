---
title: Ask User
description: An interactive clarifying-question card — single- or multi-select options with keyboard navigation and a step flow.
---

Ask User renders the interactive prompt a model raises to gather a choice. It
handles option registration, highlight, and keyboard navigation in the package;
the wrapper draws each option as a radio (single-select) or checkbox
(multi-select) card, plus a step header for multi-question flows and a
read-only summary of answered exchanges.

<ComponentPreview name="ask-user-basic" />

## Installation

```bash
bunx shadcn@latest add @intentface/ask-user
```

## Anatomy

```tsx
<AskUser>
  <AskUser.Header>
    <AskUser.Label>{question}</AskUser.Label>
  </AskUser.Header>
  <AskUser.Options value={value} onValueChange={setValue}>
    <AskUser.Option value={option.value}>
      <AskUser.OptionInput />
      <AskUser.OptionContent>
        <AskUser.OptionLabel>{option.label}</AskUser.OptionLabel>
        <AskUser.OptionDescription>{option.description}</AskUser.OptionDescription>
      </AskUser.OptionContent>
    </AskUser.Option>
  </AskUser.Options>
  <AskUser.Hints>{/* shortcut hints */}</AskUser.Hints>
</AskUser>
```

For multi-question flows, add navigation to the header:

```tsx
<AskUser.Header>
  <AskUser.Label>{question}</AskUser.Label>
  <AskUser.Navigation>
    <AskUser.Previous />
    <AskUser.StepLabel />
    <AskUser.Next />
  </AskUser.Navigation>
</AskUser.Header>
```
