---
title: Artifact Card
description: An inline handle for a generated artifact — opens the artifacts panel; disabled while the artifact is still streaming.
---

Artifact Card is the clickable chip a message shows for a generated artifact (a
document, report, or code file). While the artifact is still streaming
(`state` `"input-streaming"`) the card is disabled and spins; once settled it
becomes a button that opens your [Artifacts Panel](/docs/primitives/artifacts-panel).

<ComponentPreview name="artifact-card-basic" />

## Installation

```bash
bunx shadcn@latest add @intentface/artifact-card
```

## Anatomy

```tsx
<ArtifactCard title={title} state={toolPart.state} onToggle={() => openArtifact(artifact)} />
```

## Props

export const rootProps = [
  { name: "title", type: "string", description: "The artifact's display title." },
  { name: "state", type: "string", description: 'The tool-part state; "input-streaming" renders the disabled, spinning state.' },
  { name: "onToggle", type: "() => void", description: "Fires on click (only when not streaming) — open/close your artifacts panel." },
];
